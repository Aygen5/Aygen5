### 📁 Featured Projects

Here are a few highlights of what I've been building to demonstrate full stack and backend architecture concepts:

#### 💳 FinanceFocus — Full Stack Personal Finance Management Platform
*A robust personal finance dashboard designed to monitor budgets, track cash flows, and manage assets with a highly responsive, modern UI.*
- **Frontend Architecture:** Built using **React**, TypeScript, and Redux Toolkit with a structured **Feature-Based Architecture**.
- **State & UI Systems:** Managed form validation via React Hook Form & Zod, state synchronization using Axios, responsive layouts via Tailwind CSS, and data visualization using Recharts.
- **Client Features:** Implemented a full light/dark Theme System, smooth routing with React Router, and simulated dynamic endpoints using a local mock API during development.
- **Backend Integration:** Currently developing and integrating the production backend using ASP.NET Core and PostgreSQL.

#### 🛍️ E-Commerce REST API — Scalable Backend Solution
*A complete backend infrastructure designed with a focus on decoupling, testability, and separation of concerns.*
- **Core Architecture:** Built with C# and ASP.NET Core using **Clean Architecture** patterns and the Repository Pattern.
- **Database Layer:** Managed data persistence with Entity Framework Core and PostgreSQL.
- **Key Features:** Implemented secure JWT-based authentication, structured order processing, catalog management, validation pipelines, and comprehensive error handling.
